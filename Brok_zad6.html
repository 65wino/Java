Rodzaje okienek:

• Okienko alert – wyświetla okienko dialogowe z informacją i przyciskiem OK.

• Okienko prompt – generuje okno, w którym użytkownik może wpisać wartość, a ta wartość jest zwracana następnie do programu.

• Okienko confirm – służy do tego, aby użytkownik coś potwierdził (stąd nazwa confirm).

Przy nadawaniu nazw zmiennym należy przestrzegać pewnych zasad:

1. Nazwa zmiennej musi się zaczynać od litery, znaku $ lub _, a nie od cyfry.

2. W nazwie można stosować litery, cyfry, znak $ oraz _.

3. Nie należy używać znaków specjalnych i słów kluczowych JavaScript jako nazw zmiennych.

Poprawne nazwy zmiennych: zmienna1, $wynik, _rozmiar, wynik_1

Błędne nazwy zmiennych: 1zmienna, wynik rozmiaru, var

Typy zmiennych w JavaScript

W JavaScript nie ma możliwości definiowania różnych typów zmiennych tak jak w C++, typy zmiennych są definiowane w trakcie ich przypisywania.

Podstawowe zmienne liczbowe w JavaScript to:

Number → Typ liczbowy

• zmienne całkowite

• zmienne przecinkowe

String → Typ tekstowy

Boolean → Typ logiczny

Null → Pusta wartość

Undefined → Typ niezidentyfikowany

Object → Obiekt

Konwersja zmiennych.

Wczytanie zmiennej z użyciem prompt wykonywane jest jako ciąg znaków, dlatego konieczna jest konwersja z ciągu znaków na wartości liczbowe, aby wykonywać obliczenia.

Przykłady konwersji:

Number("123") → 123

parseInt("12.9") → 12

parseFloat("12.9") → 12.9

Podsumowanie:

prompt zwraca tekst, więc trzeba zamienić go na liczbę przed działaniami arytmetycznymi.
